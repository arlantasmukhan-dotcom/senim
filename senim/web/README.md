# SENIM web

Фронтенд SENIM: Next.js 16, Tailwind v4, shadcn/ui (Radix + vaul), Motion, иконки Phosphor.
Вёрстка повторяет утверждённые макеты (canvas «SENIM макеты»: Main, Check, MobileResults, MobileCard). Работает поверх FastAPI-бэкенда из `../`
и ничего не меняет в его API.

| Страница | Что там |
|---|---|
| `/` | Главная: что такое SENIM, пять датчиков, фантом-двойник, точность на KazTruth |
| `/check` | Проверка ответа: форма, живой разбор по SSE, карточка полиграфа по каждому утверждению |

Браузер ходит только в Next. Route handlers `src/app/api/check` и `src/app/api/health` проксируют запросы
на бэкенд (`SENIM_API_URL`, по умолчанию `http://127.0.0.1:8000`) и отдают SSE-поток без буферизации.

## Запуск

Нужен Node 20+ и Python 3.11+. Быстрее всего из папки `senim`:

```bash
./start.sh          # бэкенд :8000 + сайт :3000, Ctrl+C останавливает оба
```

Без ключей прототип работает целиком: все экраны, кнопки, языки и форма. На экране проверки
видна подсказка, что проверка включится после добавления `OPENROUTER_API_KEY` в `senim/.env`.

Или вручную, в двух терминалах:

```bash
# терминал 1: бэкенд
cd senim
source .venv/bin/activate
uvicorn senim.app:app --reload

# терминал 2: фронтенд
cd senim/web
npm install
npm run dev
```

Откройте http://localhost:3000. Старый интерфейс на http://127.0.0.1:8000 продолжает работать.

Если бэкенд на другом адресе, создайте `.env.local` по образцу `.env.example`.

`NEXT_PUBLIC_TELEGRAM_URL`: ссылка на Telegram-бота. Пока она не задана, ссылки «Проверить в Telegram» скрыты.

Продакшен: `npm run build && npm start`.

## Устройство

- `src/lib/useCheck.ts`: запрос `/api/check` и сборка SSE-событий (`status`, `claims`, `sensor`,
  `citations`, `verdict`, `error`, `done`) в одно состояние.
- `src/lib/claims.ts`: разбивка текста на подчёркнутые фрагменты (смещения бэкенда считаются в кодовых
  точках Python, здесь они переводятся в UTF-16) и строки датчиков в карточке, собранные только из их данных.
- `src/lib/i18n.ts`: все тексты интерфейса на kk/ru/en. Язык хранится в cookie `senim.lang`.
- `src/lib/types.ts`: зеркало `senim/models.py`. Меняете схему на бэкенде, обновите и здесь.
- `src/app/globals.css`: токены в три слоя (базовые `--p-*`, смысловые, компонентные `--c-*`). В компонентах только токены, без hex.
- `src/components/ui/`: компоненты shadcn, подогнанные под макет (кнопки-таблетки, шторка с радиусом 20px).

Вердикты различаются формой подчёркивания, цвет только дублирует смысл: сплошное значит подтверждено,
пунктир значит подозрительно, двойное значит опровергнуто, точки значат нет подтверждения или идёт проверка.
Мнения выводятся серым без подчёркивания.
